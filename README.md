# 科学修仙实验室

一个将现代科学、传统修行与人类潜能探索转译为可操作训练和可证伪实验的研究型 Web 应用。

## 核心功能

- 六步修习计时：静、定、观、合、发、收
- 假设注册：区分已知事实、跨层桥接与前沿工作假说
- 实验预注册：提前锁定样本量、盲法和成功标准
- 观察日志：记录清晰度、稳定度、心理噪声与客观描述
- 本机数据保存与 JSON 导出
- 多尺度理论图谱与实验干扰项清单

## 研究原则

体验保持开放，结论接受验证。任何异常先称为信号，经过重复、换设备、盲化与第三方复制后再命名。

本工具不提供医疗建议，也不鼓励憋气、缺氧、极端禁食、剥夺睡眠或其他危险练习。

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

构建与检查：

```bash
npm test
```

## 技术结构

React 19 + TypeScript + vinext，部署目标为 Cloudflare Workers 兼容环境。当前个人记录保存在浏览器本地，不上传服务器。
